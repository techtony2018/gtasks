# V0.0.78 release evidence

## Scope

V0.0.78 repairs the reopened Agent Handoff Dispatcher UI regression:

- Task detail keeps Task Timeline at the bottom of the detail pane after TODOs,
  Artifacts, metadata, Memory Stargraph link, and slug.
- Task Timeline is collapsed by default and remains keyboard-accessible.
- Task-local timeline events suppress self-navigation controls such as Open
  Task, Open correlated Task, and Correlation.
- Agents is the only user-facing handoff surface. It retains a compact,
  default-collapsed Handoff History that reads from the same immutable handoff
  event source.
- Legacy/deep-linked `handoff-log` state routes safely into Agents with Handoff
  History opened, while backend APIs, evidence storage, exports, filters,
  pagination, Task Timeline, audit data, and correlation diagnostics remain
  preserved.
