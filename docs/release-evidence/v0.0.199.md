# V0.0.199 — Keep private credentials out of unblock plans

## Scope

- Goal execution now detects waiting questions that ask for credentials,
  tokens, API keys, passwords, secrets, OAuth values, private keys, or similar
  private input.
- Private questions are labeled `Private input required`.
- Private questions carry `private_input_required=true`.
- Private questions do not receive synthetic `answer_template` content.
- Private questions do not render inline answer forms or `Insert answer
  template` controls.
- Private questions are excluded from recommended unblock plans.
- Safe answer questions with concrete templates and a recommended Codex owner
  assignment still run through the explicit `Run recommended unblock plan`
  control.
