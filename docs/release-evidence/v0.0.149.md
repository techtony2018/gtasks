## Verified behavior

V0.0.146 keeps exact Task readback compatible with legacy pages that omit the
optional `detail` field. Those pages are treated as empty-detail tasks while
strict summary, status, due-day, and lifecycle validation remains in force.

V0.0.147 keeps exact GBrain Task readback compatible with legacy pages that
omit `summary` by falling back to the canonical page top-level `title` inside
GBrainAdapter readback. Raw domain callers using `Task.from_page` still reject
missing summaries.

V0.0.148 makes manual Goal execution refresh active: `GET
/api/goal-execution?refresh=1` wakes the bounded scheduler before status
readback. Developer handoff reported live readback where `next_run_in_seconds`
dropped from about `1799` seconds to about `29` seconds. This is still bounded
scheduler behavior, not unbounded execution.

## Boundary

This release documents readback and bounded scheduler behavior. It does not
authorize documenting planned Goal execution as current, bypassing canary or
shadow controls, creating duplicate canaries, mutating Tony/Agent tasks from
documentation, or treating legacy compatibility reads as looser write
validation.
