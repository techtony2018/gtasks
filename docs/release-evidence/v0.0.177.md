# V0.0.177 — Project current Goal execution at API top level

## Scope

- `/api/goal-execution` now mirrors the latest public Goal execution decision at the response top level:
  - `public_reason`
  - `task_slug`
  - `handoff`
- The full `last_run` payload remains unchanged for the Mission Control UI and detailed consumers.
- This is an observability/compatibility repair: current Agent work should not look empty to monitors or lightweight integrations that read only top-level fields.
