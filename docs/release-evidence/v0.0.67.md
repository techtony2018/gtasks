# V0.0.67 release evidence

## Scope

- Agent information requests remain normal canonical tasks and use `blocked`,
  one typed Tony blocker, one canonical question To Do, and one structured
  handoff projection. Mission Control does not create or restore a `waiting`
  task status.
- **Answer and Hand Back** records the immutable answer, completes the question,
  removes only the matching Tony blocker, preserves unrelated blockers, and
  returns the same task to its assigned Agent with a precise resume action and
  exact GBrain readback. Agent acknowledgement and bounded follow-up questions
  continue on that same task.
- The Calendar picker is compact, remains open while saving, verifies the saved
  calendar identifiers before closing, and reports persistent success or an
  actionable retained error. The branded read-only EventKit helper accepts the
  actual LaunchServices argument shape and performs no calendar writes.

## Independent UI/UX gate

- The first frozen candidate failed because serialized Agent slugs rendered as
  lowercase display names in handoff copy. No commit was made from that failed
  candidate.
- The repaired frozen candidate passed independent desktop `1440x1000` and
  genuine mobile `390x844` QA before commit.
- QA verified the exact Tammy handoff copy, question/answer reconciliation,
  focus, conflict preservation, read-only history, non-handoff Blocked copy,
  ordinary To Dos, compact Calendar picker layout, Saving state, verified
