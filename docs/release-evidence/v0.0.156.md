## Verified behavior

Goal execution now safely reconciles a selected canary Goal-derived active Task
to completed only after both of these are true:

1. the latest dispatcher handoff for the selected Task is `completed`; and
2. exact Artifact readback verifies at least one canonical Artifact with
   `produced_for` equal to the same Task slug.

The public reason is `completed_after_verified_handoff`, with UI copy:

`Mission Control completed the canonical task after verified Agent handoff and
Artifact readback.`

If the completed handoff lacks exact Artifact evidence, Mission Control keeps
the Task active and the Goal decision at ordinary duplicate/executing. Missing
Artifact evidence must not be treated as completion.

## Documentation boundary

This release does not make terminal handoff status alone sufficient for Task
completion. Documentation must preserve the exact Artifact `produced_for`
readback requirement and must not treat the Toddy host-route blocker as Agent
execution completion.
