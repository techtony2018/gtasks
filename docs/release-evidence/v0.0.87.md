# Mission Control V0.0.87 release evidence

## Scope

V0.0.87 repairs the local Dispatcher authority-mutation timeout exposed by the
failed Tammy to Tammy-OC V0.0.86 live canary. Durable wake-inbox acceptance
continues to precede the `received` acknowledgement, and launch remains
impossible until that acknowledgement is verified.

## Root cause

The client reused its ordinary 10-second request budget for wake, recovery,
acknowledgement, execution, and failure mutations. Those endpoints perform
canonical registration and delegation authority readback before changing the
handoff store. The client could disconnect before that readback finished,
leaving the durable inbox row in the intended fail-closed `accepted` state.
The observed server `BrokenPipeError` entries were late recovery responses to
an already disconnected client; no `handoff_received` event or partial launch
was recorded.

## Repair

- Authority-backed mutations use a bounded 60-second request timeout.
- Claim long-poll and authenticated no-side-effect preflight retain their
  ordinary request budgets.
- Existing lease fencing, idempotency keys, pending-ack retry, durable inbox
  ordering, and no-launch-before-receipt behavior are unchanged.
