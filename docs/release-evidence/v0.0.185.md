# V0.0.185 — Expose missing Goal owners

## Scope

- `/api/goal-execution.summary` and `last_run.summary` now include
  `missing_owners` for `owner_missing` decisions.
- Each `missing_owners` entry includes:
  - exact `goal_slug`;
  - exact `goal_title`;
  - `required_relationship: default_agent_for`;
  - message
    `Assign exactly one Codex Agent with a verified default_agent_for link before Mission Control can derive work from this Goal.`
- Agents > Goal execution visibly renders compact
  `Missing owner: <Goal title> — add default_agent_for` lines.
- Existing V0.0.184 `blocking_questions` behavior remains.
- Missing-owner rendering is readback/display context only. It does not create
  the `default_agent_for` relationship, choose an Agent, wake a worker, or
  authorize derived work for that Goal.
