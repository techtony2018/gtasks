# V0.0.68 release evidence

- Today and the dedicated Blocked view merge canonical blocked Agent work with
  Tony's blocked tasks and deduplicate the result by immutable task slug.
- The merge is independent of the Board's **Show agent tasks** preference, so
  work awaiting Tony or another unblock remains visible on action surfaces.

  lists, strong text, inline code, and allowlisted links without accepting raw
  HTML or `javascript:` links.
