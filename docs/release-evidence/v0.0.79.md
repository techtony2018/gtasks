# V0.0.79 release evidence

V0.0.79 repairs the reopened Agents Handoff History defect in the event-driven
Agent Handoff Dispatcher ticket.

Implemented candidate scope:

- `/api/handoff-events` now adds verified server-projected Task references
  through a privacy-safe `task_ref` projection for UI reads. A reference is
  clickable only after Mission Control verifies the canonical Task or System
  Ticket title and slug; otherwise the UI renders a non-clickable
  `Task unavailable` fallback.
- Agents Handoff History replaces the broken `Task: tasks/...` button with the
  compact inline layout `Agent - Task:<title> - status`.
- Task titles use Unicode-safe deterministic truncation at 20 visible
  graphemes, with the full title retained in accessible name/title metadata.
- Handoff cards remove redundant event-type labels such as `handoff queued`
  where status already conveys the outcome, and place timestamp plus
  detail/summary on the same compact row.
- Immutable audit ordering, filters, pagination, export, redaction, dead-letter
  status, and Task-detail self-navigation suppression are preserved.
