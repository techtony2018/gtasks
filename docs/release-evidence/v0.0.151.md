## Boundary

This release documents a readback/attention projection. It does not fabricate
handoff delivery, mutate canonical tasks, or convert terminal handoff repair
states into missing-handoff states. Current behavior must remain committed,
pushed, deployed, and health/version read back before documentation calls it
current.
