# V0.0.81 release evidence

Scope:

- Calendar navigation keeps Week/Month controls, Previous/This/Next navigation, and Show iCal Events on one desktop row when a task detail panel is open.
- TODO editing adds verified adjacent actions: Save TODO, Save & Mark Done, and Save & Complete Task.
- Save & Mark Done and Save & Complete Task preserve canonical TODO edits and require GBrain readback before reporting success.
- Save & Complete Task uses the existing canonical Task completion path and does not claim completion without verified Task readback.
- GBrain and Calendar communication status surfaces use the dark Mission Control HUD treatment.

Required gate:

- Independent pre-commit UI/UX QA at desktop 1440x1000 and genuine mobile 390x844.
- Calendar scenarios: no detail, task detail open, detail resized, iCal enabled/disabled, Calendar loading/error/status visible.
- TODO scenarios: save only, save and mark done, save and complete task, partial failure, keyboard/focus, mobile touch targets.
