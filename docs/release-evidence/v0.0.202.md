# V0.0.202 — Group repeated private Goal blockers

## Scope

- Product commit:
  `6f230ada3fccbabfe7ff3e66bbed3fa7d13005af`.
- Goal execution groups duplicate private-input blockers for the same Agent
  question.
- Grouped private actions carry `blocked_goal_count` and `related_questions`,
  so Tony can see how many Goals are blocked without rendering repeated
  credential prompts.
- The grouping keeps owner-assignment controls visible in Agents and Inbox.
- Private blockers remain non-autofilled and excluded from answer templates,
  inline forms, and recommended unblock plan writes.

## Boundary

- Grouping is display/readback compression only.
- It does not generate, prefill, submit, or one-click run private credentials.
- It does not change the safe answer plus recommended owner plan contract.
- Owner assignment remains explicit Codex-only user activation.
