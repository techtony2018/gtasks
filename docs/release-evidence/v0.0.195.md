# V0.0.195 — Add Agent answer templates

## Scope

- Goal execution waiting-question Action queue entries now include an
  `answer_template` draft.
- The Agents UI renders an editable `Insert answer template` button beside the
  inline answer textarea.
- Clicking the button fills the textarea with a structured draft and focuses
  the textarea.
- The button does not submit, answer the TODO, assign a Goal owner, acknowledge
  a handoff, wake a worker, complete a task, or mutate GBrain.
- Existing V0.0.194 exact `next_action`, V0.0.193 question detail, V0.0.190
  inline answer submission, and V0.0.192 owner recommendation behavior remain
  preserved.

## Canonical answer template

Postdeploy `/api/goal-execution` read back:

- `last_run=true`
- `last_error=null`
- `public_reason=actively_executing`
- Active public Goal execution task:
  `tasks/08ca28c3-c812-5abf-86a7-110c14cb94a5`
- `answer_question` Action queue entry includes `answer_template`

The template text is:

```text
Scope categories: [accepted/revised]
Desired outcomes: [accepted/revised]
Constraints: [accepted/revised]
First action: [approved/revised/declined]
Notes:
```

Answer submission remains the separate verified endpoint:

```text
POST /api/todos/<todo>/answer
```

with `answer`, `expected_updated_at`, `actor=people/tony-guan`,
`source=mission_control`, and UUID `idempotency_key`.
