# V0.0.209 — Submit answer-only Goal unblock recommendations

## Scope

- Product release commit:
  `87c5e013e9c28fcfcc6372ab79ebd9842ee49e51`.
- Inbox Goal execution actions can show `Submit recommended answer` when the
  only recommended unblocker is a safe `answer_question` with a concrete
  `answer_template`.
- The control performs exactly one reviewed TODO answer POST only after Tony
  clicks it.
- The answer-only path performs no owner assignment, system repair, private
  input, or OpenClaw writes.

## Evidence boundary

- V0.0.209 behavior was carried forward and reverified by the V0.0.211
  independent PASS gate at
  `artifacts/qa/v0.0.211-independent/gate-report.md`.
- Earlier V0.0.209 QA included a faulty interception attempt that accidentally
  submitted the live Family/Toddy answer and an owner assignment. That was a QA
  harness incident, not product automation.
- Documentation must not imply Mission Control auto-answers Agent questions;
  answer submission remains an explicit reviewed mutation through the existing
  `/api/todos/<todo>/answer` contract.

## Verification

- V0.0.211 independent QA answer-only fixture captured one TODO answer POST
  with the concrete template text, verified Tony actor/source/idempotency data,
  and zero owner/system/private/OpenClaw writes.
- Fresh live V0.0.211 sessions had no Action queue recommendation controls and
  live POST count zero.
