# Mission Control V0.0.88 release evidence

Status: `DEPLOYED AND VERIFIED`

## Candidate scope

V0.0.88 unifies new Mission Control Task and System Ticket Markdown through
the shared `gtasks.markdown_policy` formatter. It preserves structured,
user-authored fields while adding deterministic headings, safe external-link
handling, exact verified internal System Ticket links, and compiled-body
readback.

The candidate is prospective only. It does not bulk-migrate or silently change
historical Task or System Ticket bodies. API `display_markdown` is an optional,
display-only projection gated by the durable
`markdown_contract: unified-task-ticket-v1` marker and exact rerender
validation. Marked content edits rerender/read back the body; unmarked pages
preserve their historical body and use the existing structured fallback.
