## Scope

Today offers one explicit main mission and up to two optional personal tasks,
above the existing action lists. Native choices show the recorded next action
or an honest missing-action fallback. Choosing/clearing never creates,
reschedules, completes or otherwise writes a canonical task.

Browser-local storage contains only the local day and bounded task references.
Selections survive same-origin reload and expire on a new local day. Confirmed
terminal choices retire; reopened tasks need explicit reselection. Missing or
stale references remain unverified, not assumed deleted/completed. Known
Agent/System/QA content is suppressed even in retained stale snapshots. Storage
denial uses an honest in-tab fallback. Tabs are last-writer-wins and do not
synchronize live.

New choices require personal-task data verified within five minutes. Normal
automatic refresh is thirty minutes, so explicit Refresh may be needed before
choosing/changing after five minutes. Existing choices remain openable/clearable.
No focus timer, XP, streak, constellation, weekly log or Agent redesign shipped.
