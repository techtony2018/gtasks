## Verified behavior

Goal execution intentionally reconciles a checkpointed suppressed handoff as
`completed_after_verified_handoff` only when exact Artifact readback verifies a
canonical Artifact with `produced_for` equal to the selected Task slug.

The following states remain active/attention rather than completed:

- suppressed handoff without the qualifying checkpoint state;
- checkpointed suppressed handoff without exact Artifact evidence;
- completed/suppressed handoff where the Artifact does not point to the same
  Task through `produced_for`.
