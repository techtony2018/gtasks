# V0.0.181 — Ignore terminal Agent handoff history noise

## Scope

V0.0.180 promoted terminal dispatcher handoff states into Agent-card Needs
attention. Live Agent Work also includes completed and cancelled history rows,
some of which retain old terminal dispatcher statuses. Those history rows
should not become current card-level repair work.

V0.0.181 limits card-level dispatcher repair attention to non-terminal Agent
work (`planned`, `active`, or `blocked`). Completed and cancelled history stays
visible as history without masking current work.
