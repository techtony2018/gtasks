# V0.0.208 — Honest cold Goal execution read state

## Scope

- Product commit:
  `f723be89ea2fbcc66390d97e29db324c9e124936`.
- Goal execution status exposes cold or long scheduler reads as explicit
  `read_state` loading state.
- UI renders `Reading Goal execution…` instead of a blank/null first-read
  waiting state while remote readback is still in progress.
- This is a read-state distinction only; it is not a Goal decision or
  mutation receipt.
