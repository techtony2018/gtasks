# V0.0.217 — Show Mission Control and GBrain runtime versions together

## Scope

- Product commit:
  `aaf11c2b860ca00e163d611f07d7a798e0bc024a`.
- Mission Control reads the active GBrain runtime version from health.
- The footer and About dialog display the GBrain runtime version beside the
  Mission Control release version.
- Runtime-version failures use an explicit unavailable label and must not
  expose raw runtime errors.

## Boundary

- GBrain version display is readback context only.
- It does not mutate GBrain, change task data, or prove any task refresh has
  completed.

## Verification

- Release catalog includes V0.0.217 with health, footer, About dialog, GBrain
  runtime version, and unavailable fallback contracts.
