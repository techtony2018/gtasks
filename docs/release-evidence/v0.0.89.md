review relationship. The exact legacy Artifact was valid and returned HTTP
`200`, but its historical typed edges predated the `link_source: gtasks`
marker. A backend-only TDD repair now accepts such an otherwise exact legacy
Artifact while continuing to require the new `reviews_artifact` edge itself to

domain/GBrain/server suite. No UI/runtime asset changed after the independent
