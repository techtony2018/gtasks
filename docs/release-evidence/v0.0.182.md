# V0.0.182 — Goal execution reader summary

## Scope

- `/api/goal-execution` now includes a compact reader summary at the response
  top level and at `last_run.summary`.
- The summary fields are:
  - `total_goals`
  - `needs_attention`
  - `waiting_for_tony`
  - `owner_missing`
  - `ready`
  - `in_flight`
  - `recently_completed`
  - `reasons`
  - `next_action`
- The summary is a read-only projection for dashboards and lightweight API
  consumers. It does not create Goal ownership, answer Tony-blocked work, wake
  a worker, mutate GBrain, or complete any Agent task.
