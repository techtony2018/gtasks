# V0.0.176 — Surface stale retrying Goal handoffs as worker unavailable

## Scope

- Goal execution now treats stale `retrying` handoffs the same way as stale `queued` handoffs after the worker attention window.
- Fresh `retrying` or `queued` handoffs still render as `Delivering`.
- Stale retrying work becomes `handoff_worker_unavailable` / `Needs attention` so the operator sees that no verified Agent worker has leased the retry.
- This remains compatible with the local/remote boundary: the local supervisor owns only Tammy/Tammy-OC; Timmy/Toddy are remote workers and must not be started locally.
