# V0.0.198 — Add recommended Goal unblock plan

## Scope

- Inbox Goal execution actions now include `Run recommended unblock plan` when
  both are available:
  - a concrete `answer_question` answer draft;
  - a recommended Codex owner assignment for `assign_goal_owner`.
- One reviewed click sequences the existing verified answer POST first, then
  the recommended owner assignment POST.
- The plan does not run automatically.
- The button is Inbox-only; Agents keeps the existing Action queue and does not
  duplicate the recommended-plan control.
- The button is suppressed when the template is blank, no recommended Codex
  owner exists, or the recommendation is OpenClaw-only.
