# V0.0.183 — Show Goal execution next action

## Scope

- Agents > Goal execution now visibly renders the verified Goal execution
  summary that V0.0.182 exposed through `/api/goal-execution`.
- The visible panel shows:
  - the bounded `Next action:` guidance;
  - total Goals;
  - Needs attention;
  - Waiting for Tony;
  - Missing owner;
  - In flight;
  - Recently completed.
- The rendered summary is read-only operator context. It does not mutate Goal
  ownership, answer Tony-blocked work, wake an Agent worker, expose private
  worker routes, or complete any Agent task.
