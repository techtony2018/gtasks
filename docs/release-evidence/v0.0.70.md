# V0.0.70 release evidence

## Scope

- Mission Control reads durable Agent deliverables directly from canonical
  GBrain Artifact pages. No local Artifact database, index, or synchronization
  service was added.
- Each Artifact has one producing-Agent collection membership and verified
  typed `created_by` and `produced_for` relationships. Optional Project, Goal,
  supersession, Git, and verified `/media/...` references remain explicit.
- The authenticated publication boundary derives the executing Agent from a
  private local credential and fails closed when the requested Agent or
  collection does not match. Error responses do not enumerate valid identities.
- The Artifacts surface is read-only in this release and includes Agent filters,
  Task-to-Artifact navigation, safe Markdown rendering, bounded pagination,
  responsive detail presentation, and exact focus restoration.
- Agent publication instructions are tracked under
  `config/agent-artifact-protocol`. Installed automation TOML remains rendered
  state only; the verifier checks drift without overwriting schedules or fixed
  Codex task IDs.
