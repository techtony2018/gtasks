# V0.0.197 — Surface Goal actions in Inbox

## Scope

- Inbox now surfaces a dedicated expanded `Goal execution actions` section.
- The section shows Tony-owned Goal execution actions from the verified Action
  queue, including waiting Agent questions and missing Goal-owner assignments.
- It reuses the same explicit inline answer/template and Codex-only assignment
  controls already available in Agents.
- It does not automatically answer a TODO, assign a Goal owner, acknowledge a
  handoff, wake a worker, complete a task, or mutate GBrain.

## Phase summary

This release stops the current broad Goal-execution improvement pass:

- V0.0.195 added editable answer templates.
- V0.0.196 made the answer template concrete.
- V0.0.197 moved Goal execution actions into Inbox for central Needs Attention
  triage.

Future Goal-execution improvements should be scoped as a new pass rather than
implicitly continuing this sequence.
