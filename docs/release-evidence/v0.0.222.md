# V0.0.222 — Retire OpenClaw Agent authority and keep three Codex workers

## Scope

- Mission Control release commits run from
  `8eaa96611607974d4b2489645aeaa804d30f4378` through terminal commit
  `35c15c38afffd0bf28e5a24c2d688b0039bc6478`.
- The supported Agent roster is exactly `agents/tammy`, `agents/timmy`, and
  `agents/toddy`, one fixed Codex task and one singleton Dispatcher on each
  registered machine.
- Mission Control no longer grants current authority to OpenClaw Agent
  identities, roles, Goal ownership, delegation leases, paired supervisors,
  provisioning paths, activation controls, or execution adapters. Historical
  receipts remain readable as audit evidence, not current instructions.
- Independent global OpenClaw gateways remain installed and running as
  separate platform services. They are not Mission Control Agents and were not
  stopped or uninstalled by this release.

## Current boundary

Mission Control and Memory Stargraph contain no supported path that can create,
activate, assign, lease to, or execute work as a retired OpenClaw Agent. The
three-machine Codex fleet remains the sole Agent execution boundary. Historical

separate, non-authoritative platform services.
