# V0.0.77 release evidence

Status: `VERIFIED`

## Candidate scope

- Mission Control classifies Tony answers by semantic effect, not by storage
  field. A Tony answer represented as task data, body/detail text, TODO detail,
  TODO comments, or the verified Answer and Hand Back path can produce the same
  actionable Agent handoff path when the task has a canonical assigned Agent.
- Material answer revisions receive a stable semantic digest in the handoff
  idempotency input, so duplicate saves remain one effective delivery while a
  changed answer can notify the assigned Agent again.
- Tony-owned no-Agent tasks are not system routing errors. They produce
  Timeline-only informational evidence that says no Agent handoff is required
  and are excluded from failure/error counts.
- Agents now opens directly into Agent cards. The prior Agent Directory and
  Coordinator copy is removed. Each Agent card combines profile/default-goal
  information, canonical work counts/current work/recent completion, and that
  Agent's verified handoff delivery state.
- Ambiguous or unassigned handoff routing issues stay in compact system
  attention instead of being guessed onto an Agent. Handoff History is a
  default-collapsed read-only section below the cards and reuses the same
  immutable event source, filters, counts, and pagination as the Handoff Log.
- The temporary Handoff Log sidebar entry renders the same unified
  Agents/Handoff state rather than maintaining a separate interpretation.

This candidate's core behavior is semantic Tony answer classification with
material answer revisions, Tony-owned no-Agent tasks handled explicitly, and
the Agents/Handoff UI consolidated around one read-only source of truth.
