# Mission Control V0.0.101 release evidence

## Scope

Canonical System Ticket:
`tasks/b923e27b-1ed3-491c-95b9-b6e191e97cd1` — make Task detail open
immediately and recover safely when an exact GBrain read stalls.

The change is limited to the read-only Task-detail request lifecycle. It does
not mutate task data, change canonical status, or weaken exact same-slug
readback.

## Root cause and repair

Mission Control already opened the Task-detail surface immediately, coalesced
same-Task selections, and ignored late responses after a selection changed.
The remaining defect was an unbounded `fetch`: if the canonical Task endpoint
never settled, the detail surface could stay busy indefinitely and recovery
required closing or refreshing the application.

Each exact Task-detail read now owns one `AbortController` and one 15-second
watchdog. Switching Tasks or closing the detail surface aborts and invalidates
only the obsolete request. A timeout keeps the detail surface open, preserves
the available projection, exposes a clear `Try again` control, and starts one
new coalesced canonical read without reloading Mission Control. Successful
retries still require exact same-slug response reconciliation.

## Automated verification

The focused runtime contracts cover:

- immediate busy-state rendering and one-read same-Task coalescing;
- a never-settling canonical read, watchdog abort, bounded error state, and
  exactly one successful in-place retry;
- cancellation on Task switch and close;
- stale-response suppression after the selection changes;
- successful exact canonical reconciliation after retry;
- exact Board, Agent Board, Calendar, Goal, and attention-origin focus recovery
  after the detail close rerenders its source surface, including returning from
  a nested Goal Task to the still-open Goal detail and its exact Task link.

## Independent pre-commit gate

The frozen uncommitted candidate must pass independent rendered QA at desktop
`1440x1000` and genuine mobile `390x844`. QA must verify immediate busy state,
same-Task coalescing, timeout/error copy, the in-place retry, Task-switch and
close behavior, exact-origin focus restoration, responsive containment, and a
GET-only/no-GBrain-mutation session. Commit remains blocked until the report is
an explicit PASS.
