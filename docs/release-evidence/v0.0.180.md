# V0.0.180 — Surface Agent card handoff repair

## Scope

Agent Task detail already showed when a canonical task had no active domain
handoff but did have a terminal dispatcher handoff state. The Agents cards,
however, could still summarize the same task as ordinary active work. That
made recovery-needed Agent work harder to spot from the collaboration surface.

V0.0.180 promotes terminal dispatcher handoff states (`dead_letter`,
`suppressed`, and `handed_back`) into the Agent card's Current work summary:

- state: `Needs attention`;
- summary: `Verified Agent handoff needs system review`;
- detail: `Latest dispatcher status: ...`.

The Task detail panel remains the deeper recovery surface.
