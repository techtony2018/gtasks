# V0.0.215 — Let verified completion supersede stale blocked acks

## Scope

- Product commit:
  `9288e5d4e1c06cdc9b445f1fd7d489854b2e226e`.
- Remote handoff workers can let a verified completed wake-inbox result
  supersede an older pending `still_blocked` acknowledgement for the same
  handoff.
- This prevents a recovered remote worker from staying pinned to stale local
  blocked state after credentials or Artifact publisher token/config are
  fixed.
- Timmy/Toddy remain remote-only workers. This Mac's local supervisor remains
  Tammy/Tammy-OC only.

## Verification

- Release catalog includes V0.0.215 with the completed wake-inbox,
  pending still-blocked, Goal-derived task, and stale local state contract.
- Covered by the local handoff dispatcher regression added in the product
  commit.

## Operator boundary

- The completed wake-inbox result must be verified before it supersedes the
  stale blocked acknowledgement.
- This is not permission to install Timmy or Toddy locally.
- Remote workers still require the private dispatcher configuration and
  Artifact publisher token/config before they can complete Artifact-backed
  Goal work.
