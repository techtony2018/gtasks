# GTasks V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a local, empty-first personal task manager whose only canonical task state lives in GBrain.

**Architecture:** A small Python standard-library server exposes a root-scoped JSON API and serves a native HTML/CSS/JavaScript interface. The domain layer validates task fields and relationships, while a separate GBrain adapter invokes documented `gbrain call` tools without a shell and verifies every write through page and edge readback.

**Tech Stack:** Python 3.12 standard library, `unittest`, HTML5, CSS, browser-native JavaScript.

## Global Constraints

- GBrain is the only canonical task store; GTasks must not create a task database or persistence sidecar.
- Active tasks are members of `collections/tonys-tasks`; archived completed tasks are members of `collections/tonys-completed-tasks`.
- Durable goals are scoped by direct backlinks to `collections/tonys-goals`; tasks connect to one goal through `advances_goal`.
- Never discover GTasks items from the global `type: task` population; unrelated GBrain tasks already exist.
- Never seed, migrate, infer, or repair tasks in either collection.
- Never mutate GBrain’s `index` node.
- A task keeps one slug and one page history through lifecycle transitions.
- Task writes use the documented `put_page`, `add_link`, `get_page`, and `get_links` tools.
- A UI action is the authorization boundary for a mutation; startup and verification remain read-only.
- Every newly created task has a due date. If omitted, `due_day` defaults visibly to Tony's local task-creation day; an explicit due date is preserved unchanged.
- A goal with no explicit `target_day` defaults to the final calendar day of its creation quarter.
- Today section order is In Progress, Today’s Actions, Waiting and Blocked, Overdue.
- The empty state contains no fake task rows.

### Task 2: Safe GBrain adapter

**Files:**
- Create: `gtasks/gbrain.py`
- Create: `tests/test_gbrain.py`

**Interfaces:**
- Consumes: `CommandRunner.run(tool: str, params: dict) -> object`.
- Produces: `GBrainAdapter.list_collection_tasks(root_slug)`, `GBrainAdapter.list_goals()`, `GBrainAdapter.create_inbox(task)`, `GBrainAdapter.set_task_goal(task_slug, goal_slug)`, and typed adapter errors.

- [ ] **Step 1: Write failing adapter tests**

Test that reads start from `get_backlinks` on approved roots, ignore unrelated/global pages, fetch only member slugs, validate fetched task and goal pages, read `advances_goal` from outgoing task edges, call mutations without shell strings, and reject writes unless page/relationship readback matches.

- [ ] **Step 2: Run tests and verify failure**

Run: `python3 -m unittest tests.test_gbrain -v`

Expected: import failure because `gtasks.gbrain` does not exist.

- [ ] **Step 3: Implement command and adapter boundaries**

`SubprocessCommandRunner` executes:

```python
subprocess.run(
    ["gbrain", "call", tool, json.dumps(params)],
    check=False,
    capture_output=True,
    text=True,
    timeout=timeout_seconds,
)
```

Do not use `shell=True`. `create_inbox` writes the page, verifies it, adds the `member_of` edge with `link_source: "gtasks"`, then verifies that exact edge. If the page exists but edge verification fails, return a partial-write error that includes the created slug; do not silently delete or claim success.

`set_task_goal` first proves the task belongs to an approved task root and the selected goal belongs to Tony's Goals. It adds/verifies a new `advances_goal` edge before removing an old one, then performs final exact readback. Clearing a goal removes only `advances_goal` edges after explicit user action.

- [ ] **Step 4: Run adapter tests**

Run: `python3 -m unittest tests.test_gbrain -v`

Expected: all adapter tests pass.
